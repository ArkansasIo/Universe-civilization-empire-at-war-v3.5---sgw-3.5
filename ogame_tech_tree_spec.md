# 33. Technology Unlock Graph

The database should represent the tree as a graph rather than hard-coded menus.

```text
RESEARCH
   │
   ├── prerequisite → RESEARCH
   ├── prerequisite → BUILDING
   ├── prerequisite → LEVEL
   ├── prerequisite → RESOURCE
   └── unlocks → SHIP
                 BUILDING
                 DEFENSE
                 RESEARCH
                 MODULE
```

That lets your UI automatically generate:

```text
        [Energy Science]
               │
       ┌───────┴────────┐
       ↓                ↓
 [Fusion Energy]   [Solar Energy]
       │                │
       ↓                ↓
 [Fusion Drive]    [Stellar Power]
       │
       ↓
 [Advanced Cruiser]
```
